# Harmony Desk Agent

> 项目代号：Harmony Desk Agent
> GitHub 仓库名建议：`harmony-desk-agent`

> 状态：想法整理与需求验证阶段，尚未开始编码。
> 创建日期：2026-10-03

## 一句话想法

在鸿蒙手机上的独立 App 中下达任务，让电脑端 Agent 在 Win11 电脑上安全执行文件整理、数据处理、开发辅助和系统任务，并把执行过程、结果、需要确认的操作回传到手机。

## 当前定位

- 目标用户：先只服务我自己。
- 手机端：测试版 HarmonyOS 7.0。
- 电脑端：Windows 11。
- 第一期任务范围：
  - 文件 / 数据类：整理文件、批量重命名、处理表格数据、备份同步。
  - 开发 / 系统类：写代码、跑脚本、修改配置、维护开发环境。
- 二期方向：
  - 跨设备流转：手机内容传电脑处理，电脑结果回手机查看。
- 暂缓方向：
  - 模拟鼠标键盘，操控没有命令行接口的图形软件。
  - 公开上架应用市场。

## 当前最重要的判断

这个项目的核心难点不是手机 UI，而是：

1. 电脑端 Agent 如何安全地执行 AI 生成的操作；
2. 手机与电脑之间如何建立可信、加密、可穿透网络的连接；
3. 危险操作如何审批、回滚和留痕；
4. 任务状态如何在断网、重启、失败后恢复。
