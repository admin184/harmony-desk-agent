# 项目想法记录

记录日期：2026-10-03

## 1. 想要解决的问题

我希望在手机上直接让 AI 操控电脑完成任务，而不是一直坐在电脑前等待或手动执行。

典型场景：

- 手机上发一句“整理桌面上的截图，按日期重命名并归档”；
- 手机上让 AI 在电脑里写一个处理脚本，运行并返回结果；
- 手机上查看电脑任务的执行进度；
- 遇到删除、覆盖、安装软件等高风险操作时，手机上弹出确认；
- 任务完成后，手机查看输出文件、日志或摘要。

## 2. 目标设备与用户

| 项目 | 当前设定 |
|---|---|
| 目标用户 | 我自己，单人使用 |
| 手机系统 | 测试版 HarmonyOS 7.0 |
| 电脑系统 | Windows 11 |
| 手机入口 | 独立 App，不采用浏览器作为主要入口 |
| 使用范围 | 先个人工具，不做多租户系统 |

## 3. 任务范围

### 第一期做

1. 文件 / 数据类
   - 文件查找、分类、重命名、移动；
   - Excel / CSV 数据清洗与统计；
   - 批量转换、备份、同步。

2. 开发 / 系统类
   - 生成和修改脚本；
   - 在指定项目目录中执行命令；
   - 查看报错并修复；
   - 管理开发环境和常用配置。

### 第二期做

3. 跨设备流转
   - 手机上的文本、文件、链接交给电脑处理；
   - 电脑上的结果回传手机查看或保存；
   - 手机拍照/录音后由电脑端流程处理。

### 暂缓

4. 图形界面操控
   - 模拟鼠标键盘；
   - 截图识别并点击窗口；
   - 操控没有命令行接口的软件。

暂缓原因：GUI 操控的可靠性、安全性和调试成本显著高于命令行 / 脚本路线，容易拖慢第一期。

## 4. 初步系统形态

```text
鸿蒙手机 App
    ├── 任务输入 / 会话列表 / 执行日志
    ├── 高风险操作确认
    └── 文件与结果查看
          ↓ 可信加密通道
Windows Agent
    ├── 身份认证与设备绑定
    ├── 任务队列与状态机
    ├── AI 编排层
    ├── 受控工具层
    ├── 日志与审计
    └── 文件沙箱 / 工作区
```

## 5. 必须坚持的安全边界

- 手机和电脑必须先完成设备配对和身份认证；
- 通信必须加密，不能明文暴露局域网或公网端口；
- Agent 不默认使用 Windows 管理员权限；
- AI 只能通过受控工具操作电脑，不直接获得无限 Shell；
- 文件访问必须限定在白名单目录；
- 删除、移动、覆盖、下载执行、注册表修改、安装软件必须人工确认；
- 所有任务写入日志，至少保留操作时间、命令、参数、结果和错误；
- 提供紧急停止按钮；
- 重要文件先备份或进入回收区，再执行破坏性操作。

## 6. 成功标准

第一阶段成功标准：

1. 手机能向电脑发送一个明确任务；
2. 电脑能执行并回传实时状态；
3. 高风险操作能被手机确认或拒绝；
4. 任务失败后能看懂日志；
5. 连续真实使用两周，至少替代一部分手工电脑操作。
