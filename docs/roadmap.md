# 路线图草案

更新日期：2026-10-03

> 这是规划草案，不代表已确认的开发计划。

## 阶段 0：需求与技术验证

目标：确认核心工作流是否成立。

- [ ] 试用 Happier 或相近开源项目；
- [ ] 记录可满足与不满足的需求；
- [ ] 确定 1 个真实高频任务作为 MVP 场景；
- [ ] 确认鸿蒙端技术路线；
- [ ] 确认发布策略；
- [ ] 确认网络连接方案。

## 阶段 1：最小可用版本

目标：手机能安全驱动电脑完成一个真实任务。

- [ ] Windows Agent 原型；
- [ ] 手机与电脑配对；
- [ ] 任务发送与状态回传；
- [ ] 基础日志；
- [ ] 高风险操作确认；
- [ ] 指定目录访问白名单；
- [ ] 紧急停止；
- [ ] 第一个真实任务跑通。

## 阶段 2：可靠性与日常使用

目标：从演示工具变成可靠的个人助手。

- [ ] 任务历史；
- [ ] 断线重连；
- [ ] 失败恢复；
- [ ] 文件回收 / 备份；
- [ ] 常用任务模板；
- [ ] 更细粒度权限；
- [ ] 电脑端后台常驻与开机自启策略。

## 阶段 3：跨设备流转

目标：手机和电脑形成双向工作流。

- [ ] 手机文件发送到电脑任务；
- [ ] 电脑产物回传手机；
- [ ] 手机拍照 / 录音 / 剪贴板输入接入任务；
- [ ] 跨设备任务状态同步。

## 阶段 4：图形界面操控探索

目标：扩展到无命令行接口的软件。

- [ ] 调研 Windows UI Automation；
- [ ] 评估误操作风险；
- [ ] 设计只读观察模式；
- [ ] 设计 GUI 操作审批与回放；
- [ ] 明确是否值得投入。
